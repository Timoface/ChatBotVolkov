# Чат-бот «Навигатор по компании» | ВОЛКОВ ГРУПП & «Калина-Малина»

Интерактивный корпоративный веб-помощник и навигатор для сотрудников ООО «Волков» и розничной сети фермерских продуктов «Калина-Малина».

---

## 🛠 Запуск проекта

### Требования:
- Node.js 18+ (установлен Node.js v24 LTS)
- npm

### Команды:
```bash
# Установка зависимостей (уже выполнена)
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка production-бандла
npm run build
```

Приложение доступно в браузере по адресу: **http://localhost:5173/**
