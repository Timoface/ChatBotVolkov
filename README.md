# Чат-бот «Навигатор по компании» | ВОЛКОВ ГРУПП & «Калина-Малина»

Интерактивный корпоративный веб-помощник и навигатор для сотрудников ООО «Волков» и розничной сети фермерских продуктов «Калина-Малина».

---

## 📌 О проекте и решаемых задачах

На предприятии работают более **1000 человек**, включая мясоколбасные производства в **Кемерово**, **Заринске**, **Красноярске**, птицефабрику **«Кузбасский бройлер»** и более **120 магазинов** сети **«Калина-Малина»** по всей Сибири.

### Ключевые проблемы сотрудников:
1. **Сложная навигация**: Сотрудник не знает, в какой кабинет обратиться (кадры, бухгалтерия, юристы, IT, охрана труда, медпункт).
2. **Потеря времени экспертов**: Однотипные вопросы («где справка 2-НДФЛ», «когда аванс», «сломался терминал кассы», «как продлить медкнижку») отвлекают специалистов от основной работы.
3. **Разграничение прав доступа**: Работнику цеха нужны графики смен и нормы выдачи спецодежды, продавцу розницы — стандарты касс и возвраты фермерских товаров, а офисному сотруднику — бронирование переговорок и ДМС.
4. **Разновозрастная аудитория**: В компании работают как молодые стажеры, так и опытные производственники старшего возраста, которым требуется простой интерфейс, крупный шрифт и голосовое управление.

## 🎨 Фирменный стиль «Волков» и «Калина-Малина»

Приложение разработано строго в соответствии с оригинальным брендбуком и стилистикой обеих компаний:
- **Цветовая палитра**:
  - `Глубокий волковский красный`: `#C8102E` (фирменный логотип с обложки техзадания).
  - `Ягодный оттенок «Калина-Малина»`: `#E50046` и `#D10040`.
  - `Сибирский древесный/крафтовый коричневый`: `#553826` и `#3E291C` (основной цвет текста и элементов).
  - `Натуральный беж/крафт`: `#FAF7F2`, `#F4EFE6` (фон страниц и карточек).

- **Тон коммуникации**: Сибирское гостеприимство — доброжелательный, уважительный и заботливый язык без бюрократического канцелярита.

## 🚀 Основные модули и функционал

1. **💬 Умный чат-помощник («Навигатор Волков & Калина-Малина»)**:
   - Естественный диалог и семантическое распознавание вопросов.
   - Выдача карточки с **номером кабинета**, **этажом**, **внутренним телефоном** и **пошаговым маршрутом как дойти**.
   - **Голосовой ввод (микрофон)** с распознаванием речи через Web Speech API.
   - **Озвучивание ответов голосом** (Text-to-Speech) для слабовидящих или уставших сотрудников.
   - Быстрые кнопки-подсказки (Pill buttons), адаптирующиеся под выбранную роль.

2. **🗺️ Интерактивная 2D-карта кампуса и этажей**:
   - Переключение этажей: 1 этаж (Проходная, Санблок, IT, Столовая), 2 этаж (Кадры, Бухгалтерия, Розница, «Тайга»), 3 этаж (Юристы, Дирекция).
   - Клик по кабинету подсвечивает визуальный путь от входа/лестницы и открывает карточку специалистов.

3. **🏢 Справочник кабинетов и специалистов**:
   - Живой поиск по номеру кабинета (напр. `214`), фамилии сотрудника, должности или ключевому слову (`2-НДФЛ`, `касса`, `спецодежда`).
   - Прямые внутренние номера телефонов, график работы и часы личного приёма.

4. **📚 База знаний и регламентов (с фильтрацией по ролям)**:
   - Разделы: Зарплата и выплаты, Кадры и отпуска, Спецодежда и СИЗ, Медкнижки и санитария, IT и кассы, Льготы и питание.
   - Проверка прав доступа: каждый видит только то, что ему положено.

5. **📝 Модуль онлайн-заявок (Fast Tickets)**:
   - Заказ справки 2-НДФЛ (электронный скан или оригинал с синей печатью).
   - Вызов IT-специалиста при зависании кассы или 1С.
   - Заявка на замену изношенной спецодежды/СИЗ.
   - Отслеживание статуса исполнения в режиме реального времени.

6. **👓 Панель специальной доступности (Accessibility)**:
   - Переключатель **A+** (крупный шрифт с увеличенной контрастностью).
   - Режим повышенного контраста.
   - Озвучка ответов ассистента.

## 👥 Ролевая модель доступа (5 ролей)

Переключается в хедере приложения для тестирования:
1. **Работник производства** (Мясокомбинат Кемерово / Заринск / Кузбасский бройлер) — доступ к графикам смен, нормам спецодежды, санпропускнику, медосмотрам и корпоративной столовой с 70% дотацией.
2. **Сотрудник розницы «Калина-Малина»** (Магазины Сибири) — устранение сбоев касс/терминалов 1С, возвраты фермерских товаров, заказ формы, скидка 15%.
3. **Офисный специалист** — бронирование переговорных комнат («Тайга»), ЭДО, командировки, служебные записки.
4. **Новый сотрудник (Онбординг)** — адаптационный трек, где получить пропуск, контакты наставника, памятка первого дня.
5. **Руководитель / Мастер смены** — согласование отпусков, заявки на подбор персонала в цеха, акты по охране труда.

## 🛠 Запуск проекта

### Требования:
- Node.js 18+ (установлен Node.js v24 LTS)
- npm

### Команды:
```bash
# Установка зависимостей (уже выполнена)
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка production-бандла
npm run build
```

Приложение доступно в браузере по адресу: **http://localhost:5173/**
